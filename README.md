# Professional ID Card Generator

An interactive HTML-based ID card generator that creates professional-looking ID cards similar to the SMS (Stingy Men Society) card design.

## Features

- **Custom Photo**: Your photo is automatically loaded into the card
- **Customizable Fields**:
  - Organization Name
  - Organization Acronym (3-letter logo)
  - Title/Position
  - Member ID
  - Issue Date
  - Logo accent color
- **Professional Design**: Clean, modern card layout with hover effects
- **Responsive**: Works on desktop and mobile devices

## How to Use

1. **Open the Card Generator**:
   - Simply open `id-card-generator.html` in any web browser
   - Your photo is already loaded!

2. **Customize Your Card**:
   - Fill in your organization details
   - Set your title (e.g., CHAIRMAN, MEMBER, CEO)
   - Enter your member ID
   - Choose your logo accent color
   - Click "Update Card" to see changes

3. **Save Your Card**:
   - Take a screenshot of the card display
   - Or right-click and save the image
   - For best quality, use high-resolution screenshot tools
